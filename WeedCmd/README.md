# WeedCmdPlugin 2.0.0

Плагин GUI-каталога предметов для Paper 1.21.1 / Java 21.

## Сборка
1. Установите JDK 21 и Maven.
2. В корне проекта выполните `mvn clean package`.
3. Готовый файл: `target/WeedCmdPlugin.jar`.
4. Переместите JAR в `plugins/` сервера Paper и перезапустите сервер.

## Команды
- `/weedcmd` или `/wc` — открыть меню.
- `/weedcmd give <игрок> <id|modelData> [количество]` — выдать предмет.
- `/weedcmd reload` — перечитать `items.yml`.

## Права
- `weedcmd.use` — открытие меню.
- `weedcmd.give` — выдача предметов.
- `weedcmd.reload` — перезагрузка конфигурации.

Все права по умолчанию доступны операторам.

## items.yml
Пример конфигурации находится в `src/main/resources/items.yml`. При первом запуске файл копируется в папку `plugins/WeedCmdPlugin/`.

Цвета поддерживают формат `&a`, `&6`, `&l` и другие стандартные legacy-коды.

### Важное замечание
Поля `drop`, `hat`, `hide-nickname`, `use-cooldown` и `stackable` сохраняются при загрузке для совместимости с конфигурацией, но исходный плагин не содержал механик, которые используют эти параметры. В этой версии они также не активируют отдельное поведение. Для реализации таких функций нужны точные правила их работы.
